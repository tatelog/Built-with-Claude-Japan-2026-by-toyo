# 素材集め（候補）

制作ページの「素材集め」（https://claude.ai/artifact/DUcYG7De5YCdf2LpQ1V386#materials）の 2026-10-31 時点の写し。状態の更新はページ側で行う。

権利の確かめ方：
- 国立国会図書館デジタルコレクション：「インターネット公開（保護期間満了）」は申請不要（[転載について](https://www.ndl.go.jp/use/reproduction)）
- ColBase：出典を書けば商用も含め申請不要（政府標準利用規約準拠・CC BY 互換）。出典の書き方は ColBase の規約で確認
- 東京都立図書館 TOKYOアーカイブ：資料ページに「パブリックドメイン」と表示。画像使用の申請手続きの要否は要確認
- 日本の写真は 1957年以降に公表されたものは著作権が残っている可能性が高い。表示のはっきりしたものだけ使う
