## 1. DWG（= Drawing）を題材にする　【方向は合意】

### 軸になる言葉の仕掛け
英語の「Drawing」には「図面」と「描くこと」の両方の意味がある。
DWG は「図面」の意味で名付けられたが、この作品は「描くこと」を取り戻す話。
二つの意味を動画の最初と最後に置き、筋書き「設計は一周して、手に還る」とつなげる。

| 位置 | 見せ方 |
|---|---|
| 冒頭 | 黒い画面に小さく「.dwg」→ 文字がほどけて「Drawing」に。日本語は「図面」 |
| 途中（デジタイザ 0:20〜0:35） | DWG ファイルの中身をそのまま見せると、読めない文字と数字が並ぶ。先頭には AutoCAD の版を表す6文字の記号（例：AC1032）。「手で描いた Drawing が、人の読めない数字になった」を数字の壁で見せる |
| 最後 | Apple Pencil で描き終え、同じ「Drawing」に今度は「描くこと」を添える。英語は「Drawing, again.」。冒頭と対になる |

### 確かめた事実
- 拡張子 DWG は「Drawing」の略（docs/BACKGROUND.md、代表が確認済み）
- DWG ファイルの先頭6文字は版を表す記号。AutoCAD Release 1.40（1983年）は「AC1.40」、AutoCAD 2018 以降は「AC1032」
  - [Autodesk: Drawing format version codes for AutoCAD](https://autodesk.com/es/support/technical/article/drawing-version-codes-for-autocad)
  - [Wikipedia: AutoCAD version history](https://en.wikipedia.org/wiki/AutoCAD_version_history)
  - [CADforum: DWG versions](https://www.cadforum.cz/en/qaid.asp?ID=868)

### 注意
- 画面に出すのは「.dwg」「Drawing」という言葉だけ。AutoCAD の画面・ロゴは映さない。他社の商標なので、比べる・否定する形にも見せない
- この作品は DWG では書き出さない（仕様が非公開のため）。説明文で「出力は DXF・JWW・IFC」と一言添える
- 中身を見せる DWG ファイルは、自社の実案件ではなく自作のサンプル図面で作る

## 3. 冒頭の試作の経過

- v1（20秒）：.dwg → Drawing → 製図の道具・青焼き・製図室 → 「設計は、手から始まった。」
- v2（約26秒）：代表の指摘「もっとポンポン切り替えていい」「デジタルの方にもっていく」を反映
  - 切り替えを0.6秒前後に（12カット）
  - 「設計は、手から始まった。」のあと、帝国図書館の青焼き（立面）をデジタイザのカーソルで1点ずつなぞり、座標（mm）を表示
  - 青焼きが消えて線と数字だけが残る →「手の動きが、はじめて数値になった。」
  - 最後は、なぞった線から実際に作った DXF ファイル（docs/video/tools/opening_v2_trace.dxf）の中身を数字の壁として流す
  - 音はすべて仮（合成）

### OpenAI をデザインのベースにする要点（共有された分析から）
- 白地に黒の文字。主役は1つの黒い点
- 点の集まり（ドットの格子）、設計図のような細い補助線、余白
- 色は白黒を基本に、淡い青・紫・紺を少しだけ
- 終盤は写真・図面・数字の格子のコラージュ
- 借りるのは考え方だけ。OpenAI のロゴ・シンボル・専用書体・配色の組み合わせそのものは使わない
- 冒頭の試作 v2（黒地・映画風の黒帯）は、白地ベースに作り直す必要がある
