## 5. 国以外で必要になるもの（申請先ごとに異なる）

- 特定行政庁・指定確認検査機関の **確認申請の手引き・添付図書チェックリスト**
  （例：札幌市・大阪府・横浜市などが公開。施行規則 第1条の3 の明示事項を図面別に整理している）

- 消防署の指導基準

## 7. 構造計算（RC造）

### 7-1. 計算の根拠になる法令・告示（無料・自由に実装できる）

法令と告示は著作権の対象外（著作権法 第13条）なので、式や数値をそのままプログラムにしてよい。

| 根拠 | 内容 |
|---|---|
| 建築基準法施行令 第3章 第8節（第81条〜第99条） | 構造計算の全体の枠組み。荷重・外力（第83条〜第88条）、地震力（第88条）、許容応力度（第89条〜第94条）、材料強度（第95条〜第99条） |
| 建築基準法施行令 第3章 第6節（第71条〜第79条） | RC造の仕様規定（柱の主筋・帯筋、梁、床版、かぶり厚さなど） |
| 昭和55年 建設省告示 第1793号 | 地震地域係数 Z、振動特性係数 Rt、高さ方向の分布 Ai、地盤種別 |
| 昭和55年 建設省告示 第1792号 | 構造特性係数 Ds、形状係数 Fes（保有水平耐力計算） |
| 昭和55年 建設省告示 第1791号 | ルート2の確認事項（RC造の壁量・柱量など） |
| 平成19年 国土交通省告示 第594号 | 構造計算の細目（応力計算のモデル化、保有水平耐力の算定方法） |
| 平成12年 建設省告示 第1450号 | コンクリートの付着・引張り・せん断の許容応力度と材料強度 |
| 平成12年 建設省告示 第2464号 | 鋼材（鉄筋）の許容応力度と材料強度 |
| 平成12年 建設省告示 第1454号 | 風圧力（基準風速 Vo、係数 E） |
| 平成12年 建設省告示 第1455号 | 積雪荷重（垂直積雪量・多雪区域） |
| 平成12年 建設省告示 第1459号 | たわみ・振動など使用上の支障の確認 |
| 平成13年 国土交通省告示 第1113号 | 地盤の許容応力度、杭の支持力 |

※ 告示の番号と内容は、作業開始時に国交省・e-Gov で最新の改正を確認する。

### 7-3. 計算に使えるプログラム部品（オープンソース）

| 部品 | できること | ライセンス | 判断 |
|---|---|---|---|
| Pynite（PyNiteFEA） | 3D 骨組の応力・変形解析（P-Δ 含む）。Python | MIT（要 LICENSE 確認） | **第一候補**。公開サービスに組み込んでも問題になりにくい |
| OpenSees / OpenSeesPy | 非線形解析・プッシュオーバー（保有水平耐力の検討に向く） | 研究・教育・社内利用は無償。**アプリやクラウドサービスへの組み込みは商用ライセンスが必要** | 審査員が触れる公開デモには使わない |
| web-ifc / That Open Engine | ブラウザで IFC を読み書き・3D 表示 | web-ifc は MPL-2.0 とする情報が多い（要 LICENSE 確認） | BIM 図面審査に向けた IFC 書き出しに使う |
