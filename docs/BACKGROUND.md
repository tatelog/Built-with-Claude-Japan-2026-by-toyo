# 背景メモ：DWG と「手描き図面をデジタイザで数値にする」歴史

代表が確認した内容のメモ（2026-10-30）。作品の語り（デモ動画・説明文）の材料にする。

## 要点

- 拡張子 **DWG は「Drawing（図面）」の略**。AutoCAD（1982年発売）の標準形式
- 1980年代の CAD は、パソコンにデジタイザ（Summagraphics 社などのタブレットと16ボタンカーソル）を
  つないで使うのが主流。紙の図面をなぞって数値にし、タブレット上のメニューシートでコマンドを選んだ
- Autodesk はメニューシートのカスタマイズを利用者に開放し、設計者が自分専用の製図環境を作れた。
  「AutoCAD ＋ デジタイザ」が普及の一因になったとされる
- DWG はバイナリ形式で軽く速い。テキスト形式の **DXF** は他ソフトとの受け渡し用として併存
- 過去の DWG 資産の多さが囲い込みになり、事実上の標準になった

## 要検証（出典を確認してから使う）

- 「当時は紙の図面をデジタイザでデジタル化することが最優先の目的だった」という位置づけの強さ
- デジタイザとの親和性が普及の決定打だったという因果関係
- 補足：DWG の仕様は公式には公開されておらず、Open Design Alliance が解析して互換ライブラリを作った経緯がある

## この作品との関係

- **語り**：「40年前、DWG は手描きの Drawing をデジタイザで数値にした。
  いま Apple Pencil をデジタイザにして、手描きをその場で数値にし、建築確認申請まで持っていく」
  → 主張1（画像解析ではなく数値で判断する）が CAD の原点に立ち返るものだと示せる
- **出力形式**：DWG は仕様非公開で、読み書きできる部品も OSS でないため使わない。
  DXF（公開形式）・JWW・IFC で出す
